# Tic-Tac-Toe Game
A classic web-based Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

## Live Demo
Play the game live here: [https://github.io](https://github.io)

## How to Play
1. Click on any empty square on the 3x3 grid.
2. Players take turns placing 'X' and 'O'.
3. Get three in a row to win!
